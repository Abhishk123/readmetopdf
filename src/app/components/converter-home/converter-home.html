Got Questions?

Frequently Asked Questions

Answers to common questions about README to PDF conversion and jsnsworks tools.

Are my files or documentation stored on your servers?

No. All processing happens 100% locally within your browser using client-side JavaScript. Your file data never leaves your computer, making it safe for private repositories, internal project docs, and confidential notes.

What file formats are supported?

You can upload .md, .markdown, .txt files, or files simply named README with no extension. Full GitHub Flavored Markdown (tables, checklists, syntax blocks) is parsed automatically.

How does multi-page pagination work?

Long documentation files automatically break across standardized A4 pages with balanced margins. Page numbers (e.g., "Page 1 of 4") are automatically added to the footer of each sheet.

Is this converter completely free?

Yes! README to PDF by jsnsworks is completely free for individual, educational, and commercial use. The service is supported by minimal, non-intrusive advertisements.
