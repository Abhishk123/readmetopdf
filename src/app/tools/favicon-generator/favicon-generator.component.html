Favicon Implementation Guidelines

Standard 32×32 and 16×16

Modern browsers display the 32×32 favicon in browser tabs and bookmark lists, scaling down to 16×16 for compact taskbar shortcuts.

Apple Touch Icon (180×180)

iOS and Safari require a 180×180 high-resolution icon when users save web applications or bookmarks to their iPhone or iPad home screens.

HTML Link Code

Include <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png"> in your website header for seamless cross-browser branding.
