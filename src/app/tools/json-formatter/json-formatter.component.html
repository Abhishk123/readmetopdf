Frequently Asked Questions

Why does my JSON say "Unexpected token"?

Standard JSON strictly requires double quotes " around keys and strings. Single quotes ' and trailing commas after the last item will trigger syntax errors.

Can I export nested JSON to CSV?

Yes, nested objects or arrays are serialized into JSON string cells, making them easy to view in Excel or CSV readers.
