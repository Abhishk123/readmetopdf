Understanding JWT and Base64 Encoding

How JWT Tokens Work

A JSON Web Token consists of three base64url-encoded parts separated by dots: Header (metadata), Payload (user claims), and Signature (tamper-verification hash).

Base64 vs Encryption

Base64 is a binary-to-text encoding scheme, not encryption. It allows binary data and special characters to be safely sent across HTTP headers without corruption.

100% Client-Side Privacy

Your authentication tokens, passwords, and sensitive claims are never sent to external servers. All decoding executes in your local browser sandbox.

Frequently Asked Questions

Can someone steal my token by pasting it here?

No. JSNS Works executes all string manipulation completely in your browser session. No data is stored, cached, or transmitted to any server.

Why is my JWT marked EXPIRED?

JWT payloads contain an standard exp Unix timestamp. If the current time is past this timestamp, authentication providers will reject the token.
