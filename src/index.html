About JSNS Works

JSNS Works is an independent, local-first web utility suite engineered to provide reliable, high-performance tools for engineers, finance planners, content creators, and students. Traditional online utility websites often force users to upload confidential files—such as financial statements, tax records, identification cards, and proprietary source code—to unknown remote servers. In contrast, every utility at JSNS Works executes strictly inside the user's web browser using client-side JavaScript, WebAssembly, and modern HTML5 APIs. No files or private data are ever uploaded, logged, or retained.

Featured Utilities & Capabilities

1. Financial Planning & Loan EMI Calculator

Accurately plan borrowing and investments with multi-currency support (INR ₹, USD $, EUR €, GBP £, CNY ¥, RUB ₽, JPY ¥, and other Asian currencies). Calculates reducing balance Equated Monthly Installments (EMI), principal versus interest ratios, bank Fixed Deposit (FD) quarterly compounding returns, Recurring Deposit (RD) growth trajectories, and 15-year Public Provident Fund (PPF) tax-exempt wealth accumulation.

2. Client-Side PDF Merger & Combiner

Combine multiple PDF files into one clean document with custom drag-and-drop page ordering. Built with local browser memory management using pdf-lib, enabling unlimited file merging without watermarks, file size caps, or confidential data transmission.

3. High-Fidelity Image Compressor & Format Converter

Compress and convert JPG, PNG, and WebP images instantly for job applications, passports, websites, and academic submissions. Adjust compression ratios and maximum pixel dimensions with side-by-side quality comparison, saving up to 80% bandwidth with zero cloud latency.

4. URL Shortener, UTM Campaign Builder & Privacy Link Cleaner

Generate branded short URLs, construct standard Google Analytics 4 (GA4) UTM tracking codes (Source, Medium, Campaign, Term, Content), and strip intrusive tracking parameters (such as Facebook fbclid, Google gclid, and affiliate trackers) to produce clean, privacy-respecting links.

5. Developer Security & Data Encoding Suite

Inspect JSON Web Tokens (JWT) headers, claims payloads, and cryptographic signatures with expiration validation. Perform two-way UTF-8 safe Base64 encoding/decoding and URL component escaping directly in-browser.
